# 개드립 메모장

개드립(dogdrip.net) 전용 유저 메모장 크롬 익스텐션입니다.  
마음에 걸리는 유저를 클릭하면 바로 메모를 남길 수 있어요.

## 기능

- 유저 이름 클릭 시 팝업 메뉴에 메모 추가/수정/삭제 버튼 표시
- 메모 입력/수정/삭제를 커스텀 모달로 처리 (브라우저 기본 팝업 없음)
- 메모마다 작성 시간 및 수정 시간 기록
- 익스텐션 아이콘 클릭 시 저장된 메모 전체 목록 확인
- 목록에서 유저명 또는 메모 내용으로 검색 가능
- `chrome.storage.sync` 사용으로 크롬에 로그인된 기기 간 자동 동기화

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드 후 압축 해제
2. 크롬 브라우저에서 `chrome://extensions/` 접속
3. 우측 상단 **개발자 모드** 활성화
4. **압축 해제된 확장 프로그램을 로드합니다** 클릭
5. 다운로드한 폴더 선택

## 사용 방법

1. dogdrip.net에서 유저 이름을 클릭해 팝업 메뉴를 연다
2. 하단의 **메모 추가** 버튼을 클릭해 메모를 입력하고 저장
3. 이후 같은 유저의 팝업 메뉴에서 메모 내용과 수정 시간 확인 가능
4. 익스텐션 아이콘을 클릭하면 저장된 모든 메모를 한눈에 볼 수 있음

## 파일 구조

```

├── content.css     # 인페이지 메모 UI 스타일
├── popup.html      # 익스텐션 팝업 (메모 목록)
├── popup.js        # 팝업 로직 (목록 로드, 검색, 삭제)
├── icon16.png

└── icon128.png
```
